# AI Usage Statement

## Overview

AI tools were used throughout the development process to improve productivity, assist with debugging, and refine the user interface. They served as development assistants, while all final implementation decisions, integration, testing, deployment, and validation were completed by me.

## AI Tools Used

- ChatGPT
- OpenCode

## How AI Was Used

AI was used to assist with:

- Brainstorming the overall project structure and implementation approach.
- Debugging frontend and backend issues.
- Improving the user interface and responsive design.
- Refining React components and Django API integration.
- Reviewing code for best practices and maintainability.
- Writing and improving project documentation, including the README.
- Suggesting deployment and testing workflows.

## My Contribution

I independently:

- Designed the project architecture.
- Implemented and integrated the frontend and backend.
- Built the REST API using Django REST Framework.
- Implemented webpage parsing using BeautifulSoup.
- Tested the application and resolved implementation issues.
- Configured and verified deployments on Render and Vercel.
- Reviewed, validated, and finalized all generated code before including it in the project.

## Statement

AI was used as a development assistant to accelerate development and improve code quality. All engineering decisions, implementation choices, testing, deployment, and the final submitted solution represent my own work and understanding of the project.
